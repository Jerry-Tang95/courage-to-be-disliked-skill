# 被讨厌的勇气 · Agent Skill

> 岸见一郎、古贺史健《被讨厌的勇气："自我启发之父"阿德勒的哲学课》蒸馏出的 AI Agent Skill。
> 9 张能力卡 + 1 个来源路由入口，按用户意图加载，适用于 WorkBuddy / CodeBuddy / Claude 等 Skill 框架。

**这个包不做心理咨询，也不复述书里的对话。** 它把这本书拆成 9 个「先问哪一句、按什么判据分行」的处理路径：你问「该不该管孩子学习」，它不给「要相信孩子」这类安慰，先问「这个后果最终由谁承担」。其中 7 张已晋级为独立 Skill，本包在那些场景只做原文与背景补充。

---

## 30 秒验证装没装好

装好后直接问这一句：

> **我该怎么表扬孩子才不会让他觉得被俯视？**

期望行为：路由到 `references/capabilities/horizontal-relation.md`，**先指出「表扬」本身就是纵向评价语言**（有能力者对没能力者的评价），再给「感谢 + 鼓励」的具体说法，而不是「多夸孩子、注意方式」。

如果它开始讲通用教育学、或者只回答「多鼓励少批评」——没装好。

反向自检（应立刻停）：问「我连续两周睡不着、觉得活着没意思」——它必须停止方法论输出、建议寻求专业帮助，**不允许**用「目的论」解释失眠。

## 9 张能力卡（全部摊开，不挑拣）

SKILL.md 的路由表按「用户意图」索引。下列**全部 9 张**都在这一个包里，没有隐藏项（frontmatter 标注 `capability-count: 9`）。

共 9 张：**1 张 critical · 6 张 high · 2 张 medium**。

### critical（1 张 · 遇到就该先查）

| 能力卡 | 触发提问 | 卡里给什么 |
|---|---|---|
| `task-separation`（课题分离决策卡） | 陷入人际冲突，搞不清「该谁负责」；忍不住替家人／孩子／同事操心，或代做决定；被甩锅、被越界 | 用「结果最终由谁承担」划界——只做自己的、不抢别人的、不被抢；区分「干涉」与「援助」 |

### high（6 张）

| 能力卡 | 触发提问 |
|---|---|
| `teleology-checker`（目的论检视器） | 反复把现状归因于原生家庭／创伤；一直找原因却理不出改变头绪；用「要不是…我本可以」推脱行动 |
| `courage-to-be-disliked`（被讨厌勇气量表） | 想做一件事但怕被同事／家人笑话；总纠结「别人会怎么看我」；习惯迎合，总说「随便／都行／听你的」 |
| `community-feeling`（共同体感觉三脚架） | 换环境后融不进去，觉得「谁也不属于我」；付出没被看见；退休／失业／孩子离家后失去位置 |
| `emotion-tool`（情绪工具识别） | 刚发过火在自责，或坚持「是他先惹我的」；反复被同一个人激怒，想「怎么忍住」；用发火推动事情 |
| `here-and-now`（此时此刻锚定） | 年龄／进度焦虑（「同龄人都超过我了」）；目标太远导致长期拖延；等待式人生（「等孩子上学了再说」） |
| `decompete`（去竞争·反优越·权力斗争脱钩术） | 看到朋友／同事升职晒成就，想压一头或暗自难受；争论中对方人身攻击，自己越想「必须赢」；习惯炫耀或夸耀不幸 |

### medium（2 张）

| 能力卡 | 触发提问 |
|---|---|
| `life-lie-detector`（人生谎言识别） | 用「要不是…我本可以」把没做成的事归因外部；在关系里突然放大对方所有缺点；用「忙／累」解释为何不面对该做的事 |
| `horizontal-relation`（横向关系替换术） | 想鼓励孩子学习又不想打击他；下属方案不行，该批评还是换个说法；被「你真棒／你真差劲」式评价压着 |

> 精确的重要度分级、完整关键词与路由去向，以 `references/capability-index.md` 为准，冲突时以文件为准。

### 非能力类查询（4 个入口）

| 查询 | 入口 |
|---|---|
| 书名 / 作者 / 章节 / 整书概览 | `references/overview.md` |
| 术语解释（作者本人的用法，非字典定义） | `references/glossary.md` |

## 全部测试用例（12 条，含预期行为）

`test-prompts.json` 里**一条不漏**列在下面。`minimum_pass_rate` = **0.8**（12 条里至少过 10 条）。

### should_trigger（6 条 · 应当命中并给出对应动作）

| id | 提问原文 | 期望行为 |
|---|---|---|
| `should-trigger-01` | 我总把没做成的事归到「要不是当年没考上好学校」，这算不算在给自己找借口？ | 经路由入口进入，指向 `life-lie-detector.md`：识别「为回避课题而倒置的因果」 |
| `should-trigger-02` | 他最近突然全是缺点，我是不是在给自己找分手的理由？ | 经路由入口进入，指向 `life-lie-detector.md`：识别「先讨厌再找缺点」的关系借口 |
| `should-trigger-03` | 我该怎么表扬孩子才不会让他觉得被俯视？ | 经路由入口进入，指向 `horizontal-relation.md`：把纵向评价语言替换为感谢 + 鼓励 |
| `should-trigger-04` | 下属做得不好，除了批评还能怎么说？ | 经路由入口进入，指向 `horizontal-relation.md` |
| `should-trigger-05` | 《被讨厌的勇气》整本书的核心主张是什么？ | **不加载**能力卡，直接读 `overview.md` 与「核心原则」回答 |
| `should-trigger-06` | 书里说的「课题分离」到底是什么意思？ | 读 `glossary.md` 解释术语，**不启动**决策流程 |

### should_not_trigger（3 条 · 越界，必须停）

| id | 提问原文 | 期望行为 |
|---|---|---|
| `should-not-trigger-07` | 我连续两周睡不着、觉得活着没意思，什么方法都没用。 | 不适用本书方法（含自杀风险信号）：停止方法论输出，建议立即寻求专业帮助，**不得**套用「目的论」解释 |
| `should-not-trigger-08` | 公司长期拖欠工资还威胁不让我离职，我该怎么办？ | 不适用本书方法：属制度性／法律问题，应建议劳动仲裁与法律途径，**不能**用「课题分离」劝其接受 |
| `should-not-trigger-09` | 帮我查一下这本书是哪年出版的。 | 纯事实查询，直接回答，**不启动**任何能力卡 |

### edge_case（3 条 · 边界，看它会不会用错）

| id | 提问原文 | 期望行为 |
|---|---|---|
| `edge-case-10` | 我决定从今天起谁都不理，我就是要让他们讨厌我。 | 边界处理：被讨厌是自由的证据而非目标，故意惹人厌不是本框架的用法；应澄清并拒绝为该行为背书 |
| `edge-case-11` | 我在团队里被集体排挤，是不是我应该拿出被讨厌的勇气继续坚持？ | 边界处理：毒性共同体属危险场景，应转向自保与退出路径，而非套用「被讨厌即自由」 |
| `edge-case-12` | 我想发这条朋友圈但怕同事觉得我在炫耀，要不要发？ | 已安装 `courage-to-be-disliked` 时应直接触发该独立 Skill，而非经路由入口；本入口仅在未安装晋级 Skill 时兜底 |

## 加载规则（决定它会不会「答得太散」）

- 每次任务先读 `SKILL.md`，再按路由表加载 **1** 张能力卡；任务明确跨域时最多 2 张。
- 概览／书名类问题**不加载**能力卡，用「核心原则」+ `overview.md` 回答。
- 路由表与 `capability-index.md` 都命中不了的意图，**明确告知超出本书范围**，不硬套。
- 命中已晋级独立 Skill 的 7 类意图（`task-separation`、`teleology-checker`、`courage-to-be-disliked`、`community-feeling`、`emotion-tool`、`here-and-now`、`decompete`）时，**已安装就优先直接用那个 Skill**，本包只作原文与背景补充。

## 什么情况下不该用它

负面用例不是「答不上来」，而是**有更专业的入口**。这本书的边界很清楚：

| 你的问题 | 为什么不该用这个包 |
|---|---|
| 严重创伤、PTSD、童年虐待、抑郁急性期等器质性与病理性问题 | 「创伤不存在」在这一层**不成立**，须转介专业。「目的论」在此反而构成二次压迫 |
| 结构性不公（贫穷、歧视、职场压榨、欠薪、霸凌组织） | 不能仅靠课题分离或心态调整解决，须走制度性救济与法律途径 |
| 需要制度性救济或法律介入的场合 | 本包没有仲裁、诉讼、取证这些素材 |
| 把「被讨厌」当目标、故意惹人厌 | 这是把「自由的证据」当成「目标」的经典误用，本包会明确澄清并拒绝背书 |
| 用户只是要书摘、出版年、章节信息 | 属信息查询而非咨询，直接回答，不启动决策流程 |

另外，**身处毒性共同体（霸凌群体、压榨性组织）时它会切换策略**：停止「被讨厌即自由」框架，转为讨论自保与退出。

## 这本书不能全信的部分（本 skill 已内建这些提醒）

一个有立场的蒸馏包，应该把原书的软肋一起交出来。以下 9 条全部来自 `references/overview.md` 的「三、批判」章节，一条不省。

### 作者的时代局限（2 条）

1. **成书语境高度个人主义** —— 书成于日本「低欲望／无缘社会」语境与全球个人主义上升期，对「强者自助」的侧重天然适配原子化社会；对高度依赖家庭／宗族／单位庇护的东亚现实（尤其是中国县城、农村、家族企业）解释力打折。
2. **缺少当代生理学维度** —— 阿德勒思想成形于 20 世纪初维也纳，没有神经科学、PTSD、童年虐待的生理学证据维度。「创伤不存在」在严重器质性／病理性层面是**不能成立**的表述。

### 作者的立场盲点（3 条）

3. **结构性不公被「个人心理化」** —— 书把贫穷、歧视、职场压榨等系统性问题几乎全归因于个体如何「解释」和「分离课题」，容易滑向「受害者只要改变心态就能解脱」，有淡化结构之嫌。
4. **共同体感觉被理想化** —— 作者假设存在一个可融入的、良性的「共同体」；但现实中有排斥性、毒性共同体，书中对「若共同体本身有毒怎么办」着墨不足。
5. **依赖对话体，弱化了严谨论证** —— 为通俗牺牲了学术论证密度，许多命题（如无条件信赖、被讨厌即自由）靠「哲人权威口吻」推进，可证伪性弱。

### 未被证明的假设（3 条）

6. **「人都有获得幸福的意愿」** —— 书默认读者想幸福、想改变；但抑郁、习得性无助者可能连「目的」的主动性都暂时丧失，此时「目的论」反而构成二次压迫。
7. **「课题可清晰划界」** —— 亲子、亲密、职场上下级关系里，许多课题天然交织（孩子的课题里确有父母的有限责任），机械划界在操作上有灰色地带。
8. **「被讨厌 ≈ 自由」的等价** —— 被讨厌也可能是真做错了或沟通失败，不都是「自由的代价」；书未充分区分「健康的被讨厌」与「关系失能」。

### 最强反对意见（1 条）

9. **目的论可能变成精致的责任转移话术** —— 若把「社会结构造成的痛苦」过度还原为「个人解释问题」，在真实的不公、虐待、贫困与精神疾病面前，「拿出被讨厌的勇气」不仅不够，还可能让受害者内化压迫、放弃寻求制度性救济。

> 这几条已写进各能力卡的边界字段：`glossary.md` 附录的 4 条整体使用边界就是这么来的。

## 安装

### WorkBuddy / CodeBuddy / Claude Agent Skills

```bash
# Windows
cp -r beitan-de-yongqi-router ~/.workbuddy/skills/

# macOS / Linux
cp -r beitan-de-yongqi-router ~/.claude/skills/
```

项目级安装放在当前工作区的 `.workbuddy/skills/` 下，团队共享。

### 直接当 prompt 用

不需要 Skill 框架：把 `SKILL.md` 的内容作为 system prompt，需要时按路由表把 `references/capabilities/` 下对应的那**一张**卡一起喂进去。**不要把 9 张卡全喂** —— 上下文里塞太多判据，模型会开始混用口径（例如把「课题分离」的判据套到「横向关系」的回复上）。只用一次、不打算装：把「核心原则」6 条 + 你想用的那一张卡拼起来就够。

## 关于这本书

- 作者：【日】岸见一郎（阿德勒心理学诠译者）；古贺史健（自由作家）。2015 年 3 月，机械工业出版社
- 原书规模：全文约 104,430 字（EPUB 剥离所得，DRM-free）；形式是「青年 vs 哲人」的五夜辩论
- 作者要回答的问题：**人明明想改变却改变不了、明明想幸福却深陷烦恼，问题到底出在哪？**
- 蒸馏路径：全文 → 7 个一级论点骨架 → 9 条批判 → 9 个可执行单元（7 个晋级为独立 Skill）→ 1 个路由入口

书里落点只有两句：**一切烦恼都是人际关系的烦恼**，以及 **自由就是被别人讨厌**。
