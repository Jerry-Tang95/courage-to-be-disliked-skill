# 《被讨厌的勇气："自我启发之父"阿德勒的哲学课》 — 来源路由入口（compact pack）

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 严重创伤、PTSD、童年虐待、抑郁急性期等器质性与病理性问题（"创伤不存在"在此不成立，须转介专业）
- 结构性不公（贫穷、歧视、职场压榨）不能仅靠课题分离或心态调整解决
- 把"被讨厌"当目标、故意惹人厌
- 需要制度性救济或法律介入的场合

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 目的论取代原因论：不是过去决定现在，而是现在的目的在驱动行为
2. 一切烦恼都是人际关系的烦恼，解法从课题分离入手
3. 自卑感是健康推力，把自卑当借口（自卑情结/优越情结）才是问题
4. 自由的代价是被别人讨厌；寻求认可等于把人生遥控器交给他人
5. 幸福的终点是共同体感觉：自我接纳 + 他者信赖 + 他者贡献
6. 人生是点的连续，意义由自己在此时此刻赋予
