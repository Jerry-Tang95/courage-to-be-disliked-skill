# 共同体感觉三脚架（自我接纳·他者信赖·他者贡献）

## R — 原文 (Reading)

> 这三者是缺一不可的整体。正因为接受了真实的自我——也就是"自我接纳"——才能够不惧背叛地做到"他者信赖"；而且，正因为对他人给予无条件的信赖并能够视他人为自己的伙伴，才能够做到"他者贡献"；同时，正因为对他人有所贡献，才能够体会到"我对他人有用"进而接受真实的自己，做到"自我接纳"。
>
> — 岸见一郎；古贺史健，第五夜「年轻人也有胜过长者之处」

---

## I — 方法论骨架 (Interpretation)

这个方法论回答的是一个具体问题：**当一个人感到"我在这里没有位置"时，该从哪里下手。**

常规答案是"多社交、多让别人认可你"——先被接纳，才有归属感。本方法论把顺序整个倒过来：归属感不是别人发给你的，是你自己挣来的；挣的方式是先贡献，而不是先被需要。

它由三个互相支撑的支点构成，缺一个就会塌：

1. **自我接纳**——不是喊"我能行"（那是对自己撒谎），而是承认自己现在只有 60 分，然后只在"能改的部分"上使劲。把事情分成"被给予的、改不了的"和"怎么用它、可以改的"两堆，只动第二堆。
2. **他者信赖**——把"信赖"和"信用"分开。信用要抵押、要对方先证明自己；信赖不附条件。别人会不会背叛，是对方的事，不是你的判断题；你唯一要决定的是"我要不要把这个人当伙伴"。这不是道德要求，是把关系从提防状态里拉出来的技术手段。
3. **他者贡献**——不是自我牺牲，是为了确认"我对别人有用"。关键在于贡献感是**主观**的：只要你自己确信这件事对别人有用，就成立，**不需要对方来确认或道谢**。一旦你开始等对方的"谢谢"，这套东西立刻退化成讨好。

三者形成闭环：接纳真实的自己 → 才敢不设条件地信赖别人 → 才能把别人当伙伴去贡献 → 贡献带来"我有用"的确信 → 又反过来支撑自我接纳。

还有两条配套规则：**贡献可以按"存在标准"而不只是"行为标准"**算（卧病、失业、退休的人不是零价值）；**共同体不止一个**，眼前这个待不下去，就去更大的那个。

## A1 — 书中的应用 (Past Application)

### 案例 1: 60 分的自己（c38 · 自我接纳）
- **问题**: 青年追问，改变对"我"的看法，是不是就是"更积极、获得更强的自我肯定感、凡事都朝前看"。
- **方法论的使用**: 哲人拒绝了这个方向，用考试分数把两种做法摆在一起对照——
  > 对得了60分的自己说"这次只是运气不好，真正的自己能得100分"，这就是自我肯定；与此相对，在诚实地接受60分的自己的基础上努力思考"如何才能接近100分"，这就是自我接纳。
  > — 第五夜「不是肯定自我，而是接纳自我」
- **结论**: 自我肯定是"容易导致优越情结的想法，是对自己撒谎的生活方式"；正确的入口是自我接纳 + "肯定性的达观"——分清能改的和不能改的，只在能改的地方投入力气。
- **结果**: 青年从"要不要更积极"的路口被扳到另一条路上；哲人由此把"接受不能更换的事物"确立为三脚架的第一脚，也为后面的"甘于平凡的勇气"铺好了地基（不必二选一地做"特别优秀"或"特别差劲"）。

### 案例 2: 银行贷款要抵押（c39 · 他者信赖）
- **问题**: 青年坚持"无条件地信赖别人只会遭到背叛"，因此拒绝放下条件。
- **方法论的使用**: 哲人先用银行把"信用"这个日常做法暴露出来——
  > 想要从银行贷款，就必须提供某些抵押。银行会估算抵押价值然后贷给你相应的金额。"如果你还的话我就借给你"或是"只借给你能够偿还的份额"，这种态度并不是信赖，而是信用。
  > — 第五夜「信用和信赖有何区别?」
  然后接上课题分离：**"决定背不背叛的不是你，那是他人的课题。你只需要考虑'我该怎么做'。"**
- **结论**: "如果对方讲信用我也给予信任"只是抵押交易，不可能产生深度关系；无条件信赖是构建横向关系的手段，被背叛的风险不归你管。
- **结果**: 青年"怕被背叛所以不信赖"的前提被拆掉——他反对的其实不是信赖，而是承担风险；哲人由此把第二脚立住：你能决定的只有"我信不信"。

### 案例 3: 独自收拾餐桌的妻子（c33 · 他者贡献）
- **问题**: 晚饭后满桌餐具，孩子回房、丈夫看电视，只有妻子在收拾，全家都视为理所当然。按常理她会积起"为什么只有我干"的怨气。
- **方法论的使用**: 哲人不建议她去争取分工或索要感谢，而是换掉那个问题——
  > 这时候即使听不到家人的"谢谢"，也应该一边收拾餐具一边想"我对家人有用"。我们应该思考的不是他人为我做了什么，而是我能为他人做什么，并积极地加以实践。
  > — 第五夜「年轻人也有胜过长者之处」
- **结论**: 贡献感由自己给出，不必等家人确认；把家人从"占我便宜的人"重看成"伙伴"，同一件事的性质就变了。
- **结果**: 哲人指出连现实反馈都会变——焦躁地洗碗，家人不愿靠近；哼着歌洗碗，孩子可能过来帮忙，"或至少营造出一种容易帮忙的氛围"。第三脚由此落地：先贡献，归属感随后到。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **换环境后的悬空期**：搬到新城市、转学、跳槽进新团队，"谁也不认识我，我好像不属于这里"，每天很丧。
2. **付出没被看见**：家务、照护、团队里的脏活累活都在做，没人道谢，正在滑向"凭什么只有我"的怨气或"算了我也不干了"。
3. **失去角色标签**：退休、失业、休长病假、孩子离家，名片和头衔一起消失，"我现在什么都不是了"。
4. **不敢建立深度关系**：被背叛过一次之后开始对所有人设条件（"先看他值不值得"），关系全停在浅层，越来越孤独。
5. **追问幸福本身**：物质条件不差却"提不起劲""不知道活着为了什么"，在问"怎样才算幸福"。

### 语言信号 (用户的话里出现这些就应激活)

- "我没有归属感 / 找不到自己的位置" · "no sense of belonging"
- "我对谁都没用 / 我这个人没什么价值" · "worthless / I'm useless"
- "没人需要我 / 没人在乎我做了什么" · "nobody needs me"
- "融不进去 / 感觉自己是外人" · "don't fit in / like an outsider"
- "凭什么只有我在付出，没一个人说谢谢"
- "我不敢再信任人了 / 信任是要看对方值不值得的"
- "退休（失业）以后我就什么都不是了"
- "到底怎样才算幸福？" · "what is happiness / how to feel fulfilled"

### 与相邻 skill 的区分（定稿）

- 与 `task-separation` 的区别：课题分离是**入口**，处理"这件事该谁管、边界在哪"；本 skill 是**终点**，处理"划清界限之后，我和人怎么连回去"。问"我该不该管他"→ 课题分离；问"我怎么才有位置"→ 本 skill。先把课题分离清，才能在关系里不纠缠（本 skill 依赖 task-separation）。
- 与 `courage-to-be-disliked` 的区别：那是**减法**——放下认可欲求、承受被讨厌；本 skill 是**加法**——放下之后往哪投入（自我接纳/他者信赖/他者贡献）。贡献而不图认可需要被讨厌的勇气，二者常配对。
- 与 `here-and-now` 的区别：本 skill 的坐标轴是**关系**（我与他人），here-and-now 的坐标轴是**时间**（过去/未来 vs 此刻）。孤独感用本 skill，"来不及了/落后了"用 here-and-now；归属感靠"此刻贡献"获得。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **定位塌掉的是哪一脚**
   - 分别问三句诊断题：①"你能说出一件自己现在做不到、但你已经承认了的事吗？"（自我接纳）②"你最近一次不设条件地相信某人是什么时候？"（他者信赖）③"过去一周你为别人做过的一件事是什么？"（他者贡献）
   - 完成标准: 用户在三题中明确出现至少一处卡壳/回避，agent 能指名"你的问题主要在第 N 脚"，而不是笼统说"你缺共同体感觉"。
   - 判停条件: 若用户描述的是**当下正在被霸凌、家暴、被压榨性组织困住**，立刻跳出本 skill——先讨论物理退出、证据留存与外部求助（见 B 段），不要让他"先去贡献"。

2. **对症下一个当天可做的最小动作**（只发一条，不给清单）
   - 自我接纳卡壳 → 让用户写下一句"我现在做不到 ___，这是事实"，并在同一行写"我能改的那部分是 ___"。
   - 他者信赖卡壳 → 指定一件**成本可承受**的小事，不加条件地交出去（把一个任务托给同事、先付出一次不问回报的帮忙），并预先明说："他若辜负，那是他的课题。"
   - 他者贡献卡壳 → 把问题从"别人为我做了什么"改写成"我能为这里做什么"，落到一个 10 分钟内可完成的具体动作（帮人指路、回一条有用的信息、做顿饭、把公共区域收一下）。
   - 完成标准: 用户能复述出一个带时间、带对象、10 分钟内可执行的动作，且这个动作**不含"让对方感谢我/认可我"**的成分。

3. **把贡献感的判定权交回用户，并检查是否偷偷退回讨好**
   - 明确交代：做完之后不看对方反应，只自己回答一句"这件事对他有用吗"。有用 → 成立。
   - 反问一遍："如果对方完全没道谢，你还愿意做吗？"若答否，回步骤 2 换一个成本更低的动作。
   - 完成标准: 用户接受"贡献感是主观的、不需要对方确认"，且能说出一个不依赖回应的自检句。

4. **（仅当眼前共同体确实无解时）扩大共同体**
   - 提示"倾听更大共同体的声音"：眼前这个班级/公司/家庭不是全部，你同时属于行业、兴趣圈、地域、人类。
   - 完成标准: 用户列出至少一个自己已经属于、但一直没算进来的更大共同体，并给出一个进入它的具体动作。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **用户正身处毒性共同体**：霸凌群体、家暴关系、压榨性组织。此时"先贡献""无条件信赖"会直接加深伤害。正确顺序是先退出/求助/留证，再谈归属。书中给出的合法出口是"倾听更大共同体的声音"——**退出小共同体是允许的解**，不是失败。
- **用户当下要的是被共情，不是被指导**：刚经历丧失、失恋、裁员的头几天，讲"你去贡献"等于否认痛苦。先承接情绪。
- **临床问题**：抑郁、社交焦虑到功能受损、自伤风险。三脚架不是治疗，不能替代专业帮助。
- **用户的真实诉求是具体决策**（要不要管这件事、要不要接这个活）：那属于 `task-separation`，本 skill 会把话题拉偏。
- **结构性困境被当成心理问题**：低薪、歧视、无保障的雇佣关系。让用户"换个看法去贡献"会掩盖掉本该走的制度性救济路径。

### 作者在书中警告的失败模式

- **`ce14` 贡献错位——把"彼之力"错当"我之力"**：把贡献感建立在"被认可"之上。作者原话："获得贡献感的手段一旦成了'被他人认可'，最终就不得不按照他人的愿望来过自己的人生。通过认可欲求获得的贡献感没有自由。" 警戒信号：做完事后反复查看对方有没有回应、没被感谢就发怒或委屈。
- **`ce07` 自我肯定——虚假积极的优越情结**：把"接纳 60 分"偷换成"我其实能得 100 分，这次只是运气差"。这是对自己撒谎，并且是通往优越情结的路。警戒信号：只谈"我很强/我能行"的喊话，说不出任何一个自己做不到的具体事项。
- **`ce08` 工作狂——以工作逃避其他课题**：只在工作这一侧面猛做贡献，用业绩垄断家庭价值。作者判定这是人生谎言，本质是"缺乏人生和谐"。警戒信号："我拼命挣钱就是为这个家做贡献了"。
- **`ce13` 缺乏人生和谐——用"大家/总是"一般化**：抓住某一个方面（口吃、脸红、一次被冷落）就给整个世界下判决。原文："真正的问题在于无法做到自我接纳、他者信赖和他者贡献，却将焦点聚集到微不足道的一个方面并企图以此来评价整个世界。"
- **`ce02`/`ce10` 优越情结 / 把人际关系当竞争**：一旦把周围人看成对手，任何贡献都会变味成表演。

### 作者的盲点 / 时代局限

- **毒性共同体未被充分讨论**（BOOK_OVERVIEW 立场盲点）：全书默认存在一个良性、可融入的共同体，对"如果这个共同体本身有毒怎么办"着墨不足。skill 必须自己补上"退出"这个选项。
- **结构性不公被个人心理化**（BOOK_OVERVIEW 立场盲点 + 最强反对）：贫穷、歧视、职场压榨在书里几乎全被还原成"你怎么解释、怎么分离课题"。对孤立无援的人只谈"先贡献"，容易滑成"受害者改变心态即可"。保留寻求制度性救济的路径。
- **"人都有获得幸福的意愿"是未证假设**（BOOK_OVERVIEW 未证假设）：抑郁、习得性无助者可能连"主动做点什么"的能力都暂时没有。此时应优先启用**存在标准**（"仅仅存在于这里就已经对他人有用"），而不是给行为清单。
- **"无条件信赖"未处理持续受害情形**（glossary g12 边界提醒）：作者的意思是"不因为怕被背叛而不信赖"，不是"必须留在伤害你的关系里"。skill 须始终保留"可以切断关系"的出口。
- **依赖对话体、论证密度低**（BOOK_OVERVIEW 立场盲点）："幸福即贡献感"这类命题靠哲人的权威口吻推进，可证伪性弱。不要向用户宣称这是被验证的科学结论。

### 容易混淆的邻近方法论

- **≠ 团队意识 / 合群 / 多社交**：共同体感觉是"我对共同体有用"的**主观确信**，不是社交数量或被集体需要（glossary g04）。
- **≠ 自我肯定、正向心理暗示**：自我接纳明确排斥"我能行"式喊话（g11）。
- **≠ 基于信用的信任评估**：任何"先看他靠不靠得住"的做法都是信用，不是信赖（g12）。
- **≠ 自我牺牲 / 无私奉献**：作者把为他人牺牲人生的人称作"过度适应社会的人"，明确反对（g13）。
- **≠ 马斯洛式"归属与爱的需要"**：作者否定认可欲求，与"被认可是健康基本需求"的主流叙事直接冲突（g23）。
- **邻近但不同**：`horizontal-relationship`（话术层）、`task-separation`（边界层）、`here-and-now`（时间层）、`disliked-courage`（认可欲求层）。
