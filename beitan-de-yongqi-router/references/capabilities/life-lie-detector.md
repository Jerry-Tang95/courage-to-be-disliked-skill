# 人生谎言识别

## R — 原文 (Reading)

> 哲人：阿德勒把这种企图设立种种借口来回避人生课题的情况叫作"人生谎言"。对于自己目前所处的状态，把责任转嫁给别人，通过归咎于他人或者环境来回避人生课题。
>
> — 岸见一郎；古贺史健，第二夜「"人生谎言"教我们学会逃避」

---

## I — 方法论骨架 (Interpretation)

"人生谎言"不是骗别人的谎，而是骗自己、用来回避人生课题的谎。它的典型句式是"因为 A，所以我做不到 B"（要不是老板抠门我早创业了；都怪原生家庭我才会这样）。看起来在陈述事实，实际运作顺序是反的：先有"不想承担/不想改变"的目的，再去搜罗符合这个目的的缺点和借口。

识别的关键，是看因果箭头指向哪边——是真的"外部原因导致无法行动"，还是"为了不行动而把外部因素说成原因"。注意两点: 一是它从来不是善恶或道德问题，而是"勇气"问题（没勇气改变，所以编借口），所以识别时不能变成道德审判；二是客观困难真实存在，本书并不否定困难，只是指出"因果被倒置、目的在回避行动"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 梦想当小说家却从不投稿的朋友 (c08)
- **问题**: 一位年轻朋友梦想成为小说家，却总说"工作太忙"写不出作品，也从未参加过任何比赛。
- **方法论的使用**: 哲人指出，他其实是用"不参赛"保留"如果做的话我也可以"的可能性——先有"不改变的决心"，再用忙碌作借口。
- **结论**: 这是典型人生谎言：不是没时间，而是害怕落选后连"可能性"都失去，于是用借口维持现状。
- **结果**: 哲人点明"如果一直不去投稿应征，那就不会有所发展"。

### 案例 2: 恋爱中对方一切言行都令人生气 (c14)
- **问题**: 恋爱/夫妻关系中，过了某时期后对方任何言行都让人生气。
- **方法论的使用**: 哲人指出，往往先有"结束这段关系"的目的，再去事后搜集对方缺点作为材料——先有结论，再找理由。
- **结论**: 这不是对方突然变糟，而是用"讨厌"的借口回避关系课题（或回避主动结束的责任）。
- **结果**: 阿德勒将这种设立借口回避人生课题统称为"人生谎言"。

### 案例 3: 青年自述"毫不讲理的上司" (c22)
- **问题**: 青年诉苦自己有个动辄发火的上司，"被上司疏远所以无法工作，干不好全是因为那个上司"。
- **方法论的使用**: 哲人点破：这是用上司当借口逃避工作；并用课题分离指出，上司发怒是上司的课题，自己只需诚实面对自己的课题。
- **结论**: "因为上司所以没法工作"是把责任转嫁出去的人生谎言，目的是回避工作课题。
- **结果**: 哲人："无论上司怎么蛮不讲理地乱发脾气，那都不是'我'的课题。"

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户说"要不是…我本可以"，把没做成的事归因某个外部短板或他人。
2. 用户在关系里突然放大对方所有缺点、说"我早就受不了他了"。
3. 用户用"忙/累/没人帮"解释为何一直不面对该做的事（学习、创业、健身、沟通）。
4. 用户把职场不顺全归咎上司/同事/环境，自我定位为无辜受害者。

### 语言信号 (用户的话里出现这些就应激活)

- "要不是因为…我也能行" / "If it weren't for…I could have."
- "都怪…/是他害的" / "It's all because of him / the environment."
- "他让我…（所以我不行）" / "He made me…(so I can't)."
- "等…之后我就…" / "Once…happens, I'll…"

### 与相邻 skill 的区分（定稿）

- 与 `teleology-checker` 的区别: 人生谎言是目的论的具体欺骗形态——专抓"为回避课题而倒置的因果"；目的论更通用，把任何原因论归因翻转为现在的目的。先懂目的论才看得穿人生谎言（本 skill 依赖 teleology-checker）。
- 与 `decompete` 的区别: 本 skill 抓"外部归因/借口"（要不是…我本可以），去竞争抓"比较/优越/权力斗争"；优越情结与廉价的优越性追求常同时是人生谎言，二者交叠但视角不同。
- 与 `here-and-now` 的区别: 二者共用"编借口逃避"机制但入口不同——本 skill 指向"他人/环境"（都怪上司），此时此刻指向"时间"（等以后/因为过去）。作者称不活当下是"人生中最大的谎言"，是本家族的特殊成员。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **捕捉"因为 A 所以做不到 B"句式**
   - 完成标准: 用户表述中已标出具体的外部归因（某人/环境/过去），并复述其原话。

2. **反转因果箭头, 检验目的**
   - 完成标准: 给出反问——"如果真想做成 B，A 会是推力还是阻碍？"若 A 反而成了不去做的理由，则提示"先有不想做的目的，再找 A 当证据"。
   - 判停条件: 若客观困难真实且严重（创伤、虐待、生存压力），则跳到步骤 3。

3. **守边界, 不道德化, 不开脱责任方**
   - 完成标准: 已说明本 skill 不否定真实困难、不替加害方开脱，仅用于识别"自我欺骗"；并提示必要时寻求外部救济（见 B 段）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 真实的创伤、虐待、贫困、职场压榨等结构性不公——此时应优先寻求制度性/外部救济，而不是把受害者的处境说成"人生谎言"。
- 当用户处于抑郁、习得性无助，连"目的"的主动性都暂时丧失时——此时"人生谎言"框架可能构成二次压迫。

### 作者在书中警告的失败模式

- `ce03` 人生谎言·为逃避人生课题编造借口: 为了不面对人际/人生课题，先捏造一个目的（如"要讨厌 A"）再去搜集符合该目的的缺点；或用"都怪环境/他人"把责任转嫁出去，以维持"不改变"的现状。本 skill 正是 ce03 的识别与拆解方法。
- `ce01` 自卑情结——把自卑感当借口（"我因为学历低所以无法成功"），与本 skill 同源，常需联动识别。
- `ce08` 工作狂是人生谎言——以工作为借口逃避家庭、育儿等其他课题，是本 skill 在"忙碌"伪装下的典型表现。

### 作者的盲点 / 时代局限

- 来自 BOOK_OVERVIEW 第 3 节: **未被证明的假设**——"人都有获得幸福的意愿"。抑郁、习得性无助者可能暂时连"目的"的主动性都丧失，此时把处境归为"人生谎言/缺乏勇气"会变成二次压迫。**最强反对意见**——本书把"社会结构造成的痛苦"过度还原为"个人解释问题"，在真实的不公、虐待、贫困面前，"拿出被讨厌的勇气"不仅不够，还可能让受害者内化压迫、放弃寻求制度性救济。本 skill 必须保留"外部救济也是合法路径"这一出口。

### 容易混淆的邻近方法论

- `teleology-checker`（目的论检视器）: 更上位的因果翻转工具；本 skill 是其针对"回避型借口"的特化。
- `decompete`（去竞争·反优越·权力斗争脱钩术）: "廉价的优越性追求""夸耀不幸"常同时是人生谎言与优越情结，二者交叠需分清主次。
