# 被讨厌勇气量表（自由=被讨厌）

## R — 原文 (Reading)

> 自由就是被别人讨厌。……是你被某人讨厌。这是你行使自由以及活得自由的证据。自由的代价就是在人际关系中，被别人讨厌。
>
> — 岸见一郎；古贺史健, 第三夜「自由就是被别人讨厌」

---

## I — 方法论骨架 (Interpretation)

自由[g16]在阿德勒这里不是"无拘无束"，而是"在关系中不寻求他人认可、不怕被讨厌"。人一旦被认可欲求[g23]束缚，就等于把"人际关系之卡"交给了别人——别人怎么看我，决定我怎么活。被讨厌勇气量表就是一张检测表：先量一量"我这个选择，有多少是为了避免被某人讨厌/赢得某人认可"，再把"被讨厌"从"失败"重新分类为"行使自由的副作用与证据"。关键澄清：被讨厌是自由的指标，不是目标；你不是为了惹人厌而活，而是即便可能被部分人讨厌，也按自己的方针行动。它要支付的代价，是[g17]勇气——承接"做自己"带来的非议。

## A1 — 书中的应用 (Past Application)

### 案例 1: 祖母点醒"在意你脸的只有你自己" (c10)
- **问题**: 哲人的一位年轻朋友少年时总长时间对着镜子整理头发，过度在意他人评价。
- **方法论的使用**: 祖母一句话点破——"我有一位年轻的朋友，据说他少年时代总是长时间对着镜子整理头发。于是，他祖母对他说：'在意你的脸的只有你自己。'那之后，他便活得轻松了一些。"他人并不时刻监视你。
- **结论**: 放下对他人评价的过度在意，是摆脱认可欲求[g23]、拿回人际之卡的前提。
- **结果**: 朋友此后活得更轻松，不再被"别人怎么看我"绑架。

### 案例 2: 青年拿上司当借口，卡在他人手中 (c22)
- **问题**: 青年以"被上司疏远所以无法工作"推卸责任，实则是把人际之卡交给了上司。
- **方法论的使用**: 哲人指出"如果被认可欲求所束缚，那么'人际关系之卡'就会永远掌握在他人手中。"拿回卡，意味着不被上司的眼光决定自己的工作。
- **结论**: 自由需要不寻求认可[g23]的勇气；把遥控器从他人手里拿回来。
- **结果**: 青年抗拒（"您并不了解我和上司的关系"），说明认可能力解绑极反直觉却关键。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想做一件事（转行、发内容、表达观点）但怕被同事/家人/前任笑话。
2. 为迎合他人而压抑真实想法，习惯说"随便/都行/听你的"。
3. 过度纠结"别人会怎么看我"，连穿什么、发什么都要先脑补评价。
4. 总在等"更完美/更有权威了"再行动，本质是求许可。

### 语言信号 (用户的话里出现这些就应激活)

- "别人会怎么看我 / 怕被笑话" (what will they think / fear of being disliked)
- "我不想得罪人 / 不想被讨厌" (don't want to be disliked)
- "等更完美了/等别人认可了再开始" (wait until it's perfect / need approval)
- "被讨厌的勇气 / courage to be disliked" (自由就是被别人讨厌)

### 与相邻 skill 的区分（定稿）

- 与 `task-separation` 的区别: 课题分离是"划界动作"，本 skill 是"划界后招致非议时的勇气代价"。被讨厌勇气是课题分离后不再寻求认可的必然结果（本 skill 依赖 task-separation），且二者几乎总配套。
- 与 `community-feeling` 的区别: 本 skill 是减法——放下认可欲求、承受被讨厌；共同体感觉是加法——放下之后往哪投入（自我接纳/他者信赖/他者贡献）。贡献而不图认可需要被讨厌的勇气，二者常配对。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **检测认可欲求占比**
   - 完成标准: 让用户对当前选择打一个 0–10 的整数分——"0 = 完全是我自己的意愿，10 = 完全是为了避免被某人讨厌或赢得某人认可"。
   - 判分口径: 7 分以上 = 该决定主要由认可欲求驱动，继续第 2 步；3 分以下 = 认可驱动很低，本 skill 帮助有限，可转向其它议题。

2. **区分健康被讨厌 vs 关系失能**
   - 完成标准: 判断"被讨厌"属于"行使自由的副作用"还是"自己真做错／沟通失败"。
   - 判停条件: 判定为"关系失能"（真做错、沟通失败）→ 终止本 skill，转为复盘并修复沟通；判定为毒性共同体／霸凌 → 终止本 skill，转自保与退出路径。两类都不成立才进入第 3 步。

3. **划线：把对方的课题还回去**
   - 完成标准: 写下两栏——"我担心的那个人在意的是什么"（对方的课题）与"我真正想做什么"（我的课题）；确认评价归对方、选择权归自己（衔接 task-separation）。

4. **拿回遥控器**
   - 完成标准: 产出一句不被认可欲求[g23]绑架的行动宣言（如"发不发、发什么由我定"），把人际之卡握回自己手中[g16]。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 毒性共同体 / 霸凌环境: 此时"被讨厌"可能是真实危险（排挤、报复），不应鼓励硬扛，优先寻求退出或外部救济。
- 真做错或沟通失败导致的冲突: "被讨厌"是关系失能而非自由代价，应先复盘自身行为，而非归因于"他们不理解我"。
- 把"被讨厌"当目标: 故意惹人厌是把指标当目的，违背[g16]自由的本意。

### 作者在书中警告的失败模式

- `ce05` 认可欲求: 为求认可活成别人的人生，是本 skill 的检测靶心与直接对立面。
- `ce10` 把人际关系当竞争: 把他人变敌人，使"被讨厌"错位为胜负得失。
- `ce14` 贡献错位: 贡献感若依赖被认可即失去自由，与本 skill 同源陷阱。

### 作者的盲点 / 时代局限

- 未证假设: "被讨厌≈自由"的等价——被讨厌也可能是真做错或沟通失败，书未充分区分"健康的被讨厌"与"关系失能"。
- 时代局限: 成书于日本"低欲望/无缘社会"与全球个人主义上升期，对"强者自助"的侧重天然适配原子化社会，对高度依赖家庭/宗族庇护的东亚现实解释力打折。
- 最强反对: 在不公、虐待、贫困面前，仅强调"拿出被讨厌的勇气"可能让受害者内化压迫、放弃寻求制度性救济。

### 容易混淆的邻近方法论

- 自由[g16] vs 勇气[g17]: 自由是状态/结果，勇气是支付代价的能力；本 skill 给的是"检测表"，勇气支点须落到具体动作，禁止裸用"要有勇气"。
- "被讨厌"是证据不是目标: 极易被误用为故意惹人厌或孤立自己，须反复澄清。
