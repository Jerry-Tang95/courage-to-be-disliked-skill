# 课题分离决策卡

## R — 原文 (Reading)

> 我们必须从"这是谁的课题"这一观点出发，把自己的课题与别人的课题分离开来。辨别究竟是谁的课题的方法非常简单，只需要考虑一下"某种选择所带来的结果最终要由谁来承担？"
>
> — 岸见一郎；古贺史健, 第三夜

---

## I — 方法论骨架 (Interpretation)

课题分离[g03]不是冷漠，而是一套"划界"工具。人际关系里几乎所有冲突，都来自有人替别人做了决定、或逼别人替自己做了决定。它的核心只有两步：先问"这件事属于哪类人生课题[g14]（工作/交友/爱的课题）"，再用一个客观判据——"这个选择的后果最终由谁承担"——来判定归属。后果由谁承担，就是谁的课题。你只负责自己的部分，不替别人扛，也别让别人替你扛。划界之后不是断联，而是在对方主动求助时提供横向援助[g15]（把马带到水边，不强迫它喝水）。它只是入口，终点是对共同体的归属感[g04]。

## A1 — 书中的应用 (Past Application)

### 案例 1: 父母强制孩子学习 (c17)
- **问题**: 父母命令孩子学习，引发持续冲突，孩子越被逼越厌恶学习。
- **方法论的使用**: 哲人指出"学习是孩子的课题。与此相对，父母命令孩子学习就是对别人的课题妄加干涉"。用"后果由谁承担"判据——若孩子选"不学习"，成绩不好等后果的最终承担者是孩子自己，而非父母。
- **结论**: 学习是孩子的课题，父母强制属于[g15]干涉；必须把课题分离。
- **结果**: 青年从"父母有责任逼孩子学"转向接受划界判据，后续追问"分离之后再怎么做"，说明已接纳该规则。

### 案例 2: 亚历山大斩断格尔迪奥斯绳结 (c20)
- **问题**: 人际关系中的"羁绊"盘根错节，用普通方法无法解开。
- **方法论的使用**: 哲人以亚历山大大帝用剑斩断神谕绳结作比——"像这样盘综错节的绳结也就是人际关系中的'羁绊'，已经无法用普通方法解开了，必须用全新的手段将其切断。"这个"全新手段"就是课题分离。
- **结论**: 课题分离是斩断纠缠羁绊的剑，是人际关系自由的入口。
- **结果**: 哲人借此类比说明，划清界限不是残忍，而是让人从"必须替所有人负责"的泥潭中脱身。

### 案例 3: 哲人与父亲的和解 (c23)
- **问题**: 哲人童年被父亲殴打，长期不和，却总把原因归于"被打"。
- **方法论的使用**: 哲人把"与父亲的关系"断定为自己的课题——"人际关系之卡总是掌握在自己手中"。即使对方根本不想修复关系也无所谓，问题在自己有没有下定决心。
- **结论**: 关系修复之卡握在自己手中；只要改变"目的"，事情就能解决。
- **结果**: 哲人主动靠近父亲，最终获得父亲一句"谢谢"，完成和解。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 与伴侣/父母因"我是为你好"发生拉扯，对方不按自己期望改变。
2. 同事甩锅、越界，或把自己该做的决定推给你。
3. 孩子是自己的"心头肉"，却在其课题（学习/交友）上忍不住代劳、唠叨。
4. 想帮朋友但怕越界，不确定"管到哪算多"。

### 语言信号 (用户的话里出现这些就应激活)

- "我都是为你好，他怎么就是不改" (I'm only doing this for your own good / task separation)
- "这事我也没办法，都怪他…" (it's all his fault)
- "我得替他操心/替他做决定" (I have to take care of it for him)
- "课题分离""这是谁的课题" (task separation)

### 与相邻 skill 的区分（定稿）

- 与 `teleology-checker` 的区别: 本 skill 判"这件事属于谁（后果由谁承担）"，目的论检视器判"这个解释为现在哪个目的服务"。常配套——先划清界限（归属层），再用目的论追问对方/自己为何要模糊界限（归因层）。
- 与 `courage-to-be-disliked` 的区别: 本 skill 是"划界动作"，被讨厌勇气是"划界后招致非议时须支付的勇气代价"；先有分离，才谈得上承受被讨厌，二者几乎总配套。
- 与 `emotion-tool` 的区别: 本 skill 判"责任归属"，情绪工具识别判"这股情绪是不是我自己调出来的手段"。愤怒常源于把他人课题揽到自己身上（课题纠缠），所以先剥离情绪、再划清界限。
- 与 `community-feeling` 的区别: 本 skill 是共同体感觉的"入口"（这事该谁管、边界在哪），共同体感觉是"终点"（划清界限后如何与人重建归属）。问"我该不该管他"用本 skill，问"我怎么才有位置"用 community-feeling。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定位课题类别**
   - 完成标准: 能说出冲突属于工作课题 / 交友课题 / 爱的课题[g14]中的哪一类。

2. **判定归属**
   - 完成标准: 对争议点问"这个选择的后果最终由谁承担？"[g03]，写出承担者并确认课题归属。
   - 判停条件: 若处于亲子/亲密关系且后果天然交织（如孩子的课题里确有父母的有限责任），跳过"非黑即白"，进入步骤 3 的"部分分离"档。

3. **只做自己的、援助不干涉**
   - 完成标准: 产出一句"自己这一侧"的具体行动话术，且话术中不出现"你应该…""你为什么不…"等[g15]干涉句式；若对方未求助，只准备援助而不强加。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 严重创伤 / 精神疾病急性期: 此时"心理创伤不存在"的论断在器质性、病理性层面不成立，应先转介专业帮助。
- 结构性不公（贫穷、歧视、职场压榨）: 不能仅靠"课题分离"与"重新解释"解决，须保留寻求制度性/外部救济作为合法路径。
- 把"被讨厌"当目标去故意惹人厌: 那是把指标当目的，违背[g16]自由的本意。

### 作者在书中警告的失败模式

- `ce12` 纵向关系下的"干涉他人课题": 以"为你好"强加价值观，本质是纵向支配[g10]，直接破坏分离。
- `ce05` 认可欲求: 为求认可活成别人的人生，使分离失效。
- `ce06` 纵向关系下的表扬与批评: 都是操纵，易滑回干涉。
- `ce08` 工作狂: 以工作逃避其他课题的人生谎言。
- `ce01` / `ce03` 自卑情结 / 人生谎言: 把"不行动"合理化，使划界流于空谈。

### 作者的盲点 / 时代局限

- 时代局限: 成书于日本"无缘社会"语境与阿德勒 20 世纪初维也纳背景，缺乏当代神经科学、PTSD、童年虐待的生理学证据维度——"创伤不存在"在严重层面不能成立。
- 立场盲点: 书把贫穷、歧视等系统性问题几乎全归因于个体如何"解释"与"分离"，易滑向"受害者只要改变心态就能解脱"的结构淡化。
- 未证假设: "课题可清晰划界"——亲子、亲密关系、职场上下级里许多课题天然交织，机械划界在操作上有灰色地带。
- 最强反对: 阿德勒把"社会结构造成的痛苦"过度还原为"个人解释问题"，在不公、虐待、贫困与精神疾病面前，"拿出被讨厌的勇气"可能让受害者内化压迫。

### 容易混淆的邻近方法论

- 课题分离[g03]（入口）vs 共同体感觉[g04]（终点）: 分离是划界动作，共同体感觉是划界后建立归属感的归宿，不可互为代替。
- 课题分离 vs 人生谎言[g08]: 二者常同现，但分离解决"归属"，人生谎言解决"借口"，角度不同。

## 相关 skills (阶段 3 填充)

- **组合 composes-with · 目的论检视器** `teleology-checker`: 划界时常需同步检查目的论归因——先定归属层(谁的课题)，再问归因层(为何目的)。
- **组合 composes-with · 被讨厌勇气量表** `courage-to-be-disliked`: 课题分离是划界动作，被讨厌勇气是划界后招致非议时的勇气代价，二者几乎总配套。
- **组合 composes-with · 情绪工具识别** `emotion-tool`: 愤怒常源于课题纠缠(把他人课题揽到自己身上)，先剥离情绪、再用本 skill 划清界限。
- **被依赖 depends-on · 共同体感觉三脚架** `community-feeling`: 共同体感觉以本 skill 为入口——先把课题分离清，才能在关系里不纠缠(community-feeling → 本 skill 为 depends-on)。
