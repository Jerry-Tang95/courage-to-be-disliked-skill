# 决策规则速查 — 《被讨厌的勇气："自我启发之父"阿德勒的哲学课》

| 能力 | 一句话规则 |
|---|---|
| 课题分离决策卡 | 用"后果最终由谁承担"这一客观判据划清课题边界——只做自己的、不抢别人的、不被他人抢。 |
| 目的论检视器 | 把"都怪过去"倒转为"这个解释现在在为我服务什么目的"——责任从"等创伤好"移回"我现在想要什么"。 |
| 被讨厌勇气量表 | 检测认可欲求的驱动占比，把"被讨厌"从失败重分类为行使自由的副作用与证据。 |
| 共同体感觉三脚架 | 用自我接纳 + 他者信赖 + 他者贡献搭三脚架——先有"我能贡献"，才有归属感。 |
| 情绪工具识别 | 追问"这股情绪现在想替我达成什么目的"，把情绪从原因位挪到手段位，并识别权力之争不上钩。 |
| 此时此刻锚定 | 把人生从"线"重定为"点的连续"，把聚光灯打回今天能做的那一件具体小事。 |
| 去竞争·反优越·权力斗争脱钩术 | 退出三种纵向游戏——停止比较、停止用优越感掩饰自卑、停止把争论升级为胜负。 |
| 人生谎言识别 | 专抓"为回避课题而倒置的因果"——要不是…我本可以、都怪老板、用忙/累掩盖不面对。 |
| 横向关系替换术 | 把"表扬 / 批评"的纵向评价语言替换为"感谢 + 鼓励"的横向语言。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
